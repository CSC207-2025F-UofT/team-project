## Project Description

A research paper manager that links bio-informatics paper and link papers based on genes mentioned. 

### Domain

Productivity/ Acedemic Research

---

## User Stories

### User Story 1
As a bioinformatics student, I want to know how many research papers is about both gene A and gene B, so that I can plan my research.
### User Story 2
As a bioinformatics student, I want to keep track of papers I had read and sort their relationship based on gene segments mentioned.
### User Story 3
As a student reading papers, I want to save link and/or pdf in a structured manner so I can see them later.
### User Story 4
As a student researcher, I want to visualize papers sharing a particular idea like a specific gene.
